# 🖥️ Симулятор Майнинг-Фермы (Mining Farm Simulator)

Индивидуальный учебный проект по модулю **PyQt** (Яндекс.Лицей).  
Полнофункциональное десктопное приложение-симулятор с локальной реляционной базой данных SQLite3, симуляцией майнинга, контролем температур, энергопотребления, магазином, складом и биржей.

---

## 📋 О проекте

«Симулятор Майнинг-Фермы» — это экономическая игра-симулятор, в которой игрок собирает и развивает собственную криптоферму. Игроку предстоит грамотно распределять бюджет, подбирать комплектующие, балансировать мощность блоков питания (БП), следить за охлаждением и износом видеокарт, а также вовремя продавать добытый Bitcoin по выгодному биржевому курсу.

---

## 🚀 Основной функционал

### 1. 👤 Мультипрофильность и авторизация
* Выбор существующего профиля или создание нового.
* Загрузка персональной аватарки через диалог выбора файлов (`QFileDialog`, `QPixmap`).
* Система стартовых промокодов (`YANDEX`, `START`, `2026`) с начислением бонусного баланса.
* Выбор цвета интерфейса через системную палитру (`QColorDialog`).

### 2. ⛏️ Ферма 4×4 и физика симуляции
* Интерактивная стойка на 16 слотов (`QGridLayout`): установка оборудования кликом по слоту.
* Расчёт хешрейта, тепловыделения и энергопотребления в реальном времени (`QTimer` 1 сек).
* **Контроль питания:** видеокарты и кулеры требуют ватты; при превышении лимита БП срабатывает автоматическое аварийное отключение фермы.
* **Температурный режим и троттлинг:** индикатор температуры (`QProgressBar`), изменяющий цвет при нагреве (зеленый -> оранжевый -> красный). При температуре выше 90°C включается троттлинг (падение хешрейта на 50%), а при 100°C — аварийная продувка.
* **Ручной майнинг:** кнопка «⚡ Клик (+BTC)» для дополнительного заработка.
* **Лог событий:** терминал на базе `QTextBrowser` с цветным форматированием и временными метками.

### 3. ⚙️ Инженерный стенд (разгон и обслуживание)
* Интерактивное диалоговое окно по клику на установленную в стойку деталь.
* Ползунок разгона видеокарты (`QSlider`) от 50% до 150% (повышает добычу, но ускоряет нагрев и износ).
* Износ оборудования и динамический расчёт стоимости ремонта в зависимости от процента повреждений и цены видеокарты.
* Быстрое снятие детали обратно на склад.

### 4. 🛒 Магазин комплектующих
* Каталог оборудования в `QTableWidget` с фильтрацией по категориям (**GPU**, **Cooler**, **PSU**).
* Прозрачные характеристики: хешрейт (MH/s), нагрев (°C), энергопотребление (W) и цена ($).
* Валидация средств на балансе перед покупкой.

### 5. 📦 Склад и инвентарь
* Таблица купленных компонентов со статусом и состоянием.
* Быстрая установка детали со склада в свободный слот по двойному клику (`itemDoubleClicked`) с проверкой лимита питания.
* Продажа ненужного оборудования со склада за 70% от магазинной стоимости.

### 6. 💱 Биржа криптовалют
* Динамическое изменение курса BTC каждые 3 секунды.
* Мгновенная конвертация накопленной криптовалюты в доллары по текущему курсу.
* Полная история транзакций (`BUY`, `SELL`, `REPAIR`, `POWER`, `BONUS`) с отображением времени, типа и суммы.

### 7. 📄 Экспорт отчётов (Меню «Файл»)
* **Экспорт истории (.csv):** выгрузка всех финансовых операций в файл CSV с разделителем `;` и кодировкой `UTF-8-SIG` (корректно открывается в Microsoft Excel).
* **Техпаспорт фермы (.txt):** генерация текстового документа с перечислением всех установленных модулей, их состояния и характеристик профиля.

### 8. 🛠 Админ-панель
* Защищённое паролем окно (`admin`) для добавления новых комплектующих в базу данных прямо из графического интерфейса (`QFormLayout`, `QSpinBox`, `QDoubleSpinBox`).

### 9. ⌨️ Горячие клавиши
* `Пробел` — экстренная продувка фермы (мгновенно снижает температуру).
* `1` / `2` / `3` — переключение режимов мощности (Эко 0.8x / Стандарт 1.0x / Турбо 1.3x).
* `F5` — быстрая продажа всей накопленной криптовалюты.

## 🗄️ База данных (SQLite)

Архитектура базы данных (`mining_farm.db`) состоит из 4 связанных таблиц:
1. **`profiles`** — данные игрока (имя, баланс $, баланс BTC, путь к аватару, цвет темы).
2. **`catalog`** — характеристики доступных устройств (название, категория, хешрейт, ватты, нагрев, цена, описание).
3. **`inventory`** — купленное оборудование (связи с профилем и каталогом, номер слота на ферме, процент разгона, процент износа).
4. **`transactions`** — финансовый журнал (время, тип операции, сумма, курс BTC, детали).

Все финансовые операции выполняются транзакционно с защитой от ошибок (`commit` / `rollback`).

## 🛠️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/NSDKJDKL/Project.git
cd Project
```

### 2. Установка зависимостей
Требуется Python 3.10 или новее.
```bash
pip install -r requirements.txt
```

### 3. Запуск приложения
```bash
python main.py
```

### 4. Сборка исполняемого файла (.exe)
Для сборки автономного приложения без необходимости установки Python:
```bash
pyinstaller --noconsole --onefile main.py
```
Собранный файл будет находиться в папке `dist/main.exe`.
